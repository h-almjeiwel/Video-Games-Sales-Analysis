# Video Games Sales Analysis & Dashboard
### An end-to-end data analysis project using **Microsoft Excel** to analyze global video game sales.
## Key Insights:
* North America achieved the highest total video game sales
* Nintendo generated the highest overall sales among all game publishers
* Wii Sports reached over 82 million copies sold, followed by Grand Theft Auto V with over 55 million copies
* PlayStation 2 leads all gaming platforms with over 1,255 million copies sold
* Global sales peaked in 2004, mainly driven by PS2 releases
* Action and Sports are the top-selling game categories overall

## Technical Approach:
* Cleaned and prepared the data, handling missing values and ensuring data integrity
* Used VLOOKUP to incorporate the Manufacturer column from another table
* Created Pivot Tables for data aggregation and built visual charts
* Built an interactive dashboard using Slicers
